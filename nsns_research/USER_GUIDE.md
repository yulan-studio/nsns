# 神经多样性儿童研究论文助手：快速上手说明书

## 1. 这个工具是做什么的？

本工具帮助研究者完成从提出问题到形成论文初稿的资料整理：检索 PubMed、筛选摘要、取得或上传全文、记录纳入与排除、分类证据并生成草稿。它是研究辅助工具，不用于诊断儿童，也不替研究者或临床人员决定治疗。

### 产品定位

本工具的定位是：

> 可追溯、可复核的人机协作证据综合工作台。

它不是能够独立完成可靠系统综述的“全自动AI研究员”。系统综述包含研究范围、结局定义、灰色文献处理、偏倚风险和证据解释等专业及价值判断。在神经多样性研究中，“改善”还必须区分减轻焦虑、增加参与、提升生活质量，与要求儿童掩饰神经多样性特征或迎合常模之间的差别。这些决定不应由自动系统单独作出。

本工具追求的可重复性不是保证所有研究者得到完全相同的结论，而是让另一位研究者能够看到相同材料、理解每个决定的依据，并按照相同规则重新执行过程。

### 为什么使用它？

它主要用于提高研究工作的效率、透明度和规范性：

- 集中保存研究问题、检索式、检索日期和PMID；
- 批量整理摘要，减少重复查找和复制；
- 提醒研究者补齐全文、缺失数据和不良事件；
- 记录每篇研究的纳入、排除及具体理由；
- 区分原文信息、自动建议和研究者手工确认；
- 让证据分类和后续写作保持对应；
- 通过项目记录支持备份、恢复和第二位评审者复核。

它的价值是帮助研究者把判断做得更清楚、更容易检查，而不是替研究者消除所有主观判断。

### 自动解析有多准确？

当前版本**没有在人工标注的标准数据集上完成正式准确度验证**，因此不能声称“准确率为某个百分比”。任何具体准确率数字在现阶段都是没有依据的。

目前的摘要筛选、PDF解析和证据分类主要依靠关键词及规则。实际表现会受到PDF是否为扫描图片、双栏和表格排版、字符编码、关键信息位置、多组别与多时间点，以及论文用词差异等因素影响。

可以把当前自动结果理解为“帮助定位原文的线索”，不能理解为已经核验的数据：

| 自动任务 | 当前可期待的用途 | 主要风险 |
|---|---|---|
| PMID精确匹配 | PMID在PDF中清楚出现时关联论文 | PDF未写PMID或识别错误 |
| 题名匹配 | 帮助找到可能对应的文章 | 相似题名可能误匹配；低可信时不应强行关联 |
| 研究对象和干预提取 | 快速定位相关句子 | 可能混入纳入标准、背景或其他组别 |
| 量表和结局提取 | 提示可能使用的量表与结局 | 可能混淆主要、次要或探索性结局 |
| 数值、P值和置信区间 | 帮助寻找结果位置 | 容易发生组别、时间点或单位错配，必须逐项核对 |
| 缺失数据和不良事件 | 提醒研究者检查相关报告 | “未自动定位”绝不表示“没有发生” |
| 证据分类 | 提供可修改的初始建议 | 分类包含研究判断，必须查看全文确认 |

正式使用前，需要建立由研究者人工标注的论文验证集，分别计算各字段的准确率、召回率和一致性。在完成验证以前，所有自动结果都应视为“待人工确认”。

### 主要局限性

- PubMed检索不能保证覆盖所有数据库、灰色文献或未发表研究；
- 自动初筛可能漏掉术语不典型的研究，也可能保留不相关研究；
- 当前PDF解析不等同于完整的表格识别和统计数据抽取；
- 系统不能独立完成可靠的偏倚风险评价；
- 不同量表、设计、对照和时间点未必适合Meta分析；
- 自动生成的论文草稿可能过度概括，必须逐句核对原文和引用；
- 单人使用不能替代正式系统综述所需的双人独立筛选与分歧处理；
- 当前项目状态主要保存在浏览器和导出的JSON中，需要主动备份；
- 工具不提供诊断、个体治疗建议或临床决策。

## 2. 使用前准备

第一次使用只需准备一个研究问题，例如：“运动训练对自闭症儿童焦虑及相关心理行为结局有什么影响？”后续核验可准备合法取得的论文 PDF、事先确定的纳入排除标准，以及正式综述所需的第二位评审者。

第一版不要上传姓名、出生日期、地址、病历号等可识别儿童身份的信息。

## 3. 五步完成项目

### 第1步：说明想研究什么

填写：

- **研究对象**：研究谁，例如“3—18岁自闭症儿童及青少年”；
- **干预方式**：做了什么，例如“持续至少4周的结构化运动训练”；
- **比较对象**：与什么比较，例如“常规支持、等待或非运动活动”；
- **关注结果**：观察什么，例如“焦虑、情绪调节或问题行为”。

点击“生成检索式，进入下一步”。

### 第2步：检索 PubMed

系统会生成完整检索式。初次使用可以保留默认内容，排序建议使用 **Best Match（相关性）**。点击“开始检索”后会显示命中数、题名和 PMID，并保存检索日期及检索式。

**PMID** 是 PubMed 为论文分配的唯一编号，不是全文文件。点击“保存并进入筛选”进入第3步。

### 第3步：筛摘要和核验全文

1. 点击“自动初筛全部摘要”。系统提出“可能纳入”“信息不足”或“排除”建议。自动初筛不是最终决定。
2. 点击“查找并读取候选免费全文”。系统尝试从 PMC 获取合法免费全文。
3. 对仍可能纳入但没有全文的文章，在最右侧点击“上传PDF”。已排除的文章无需上传。
4. 打开全文核对研究对象、干预、结局、结果、缺失数据和不良事件。
5. 选择“全文核验后纳入”或“全文核验后排除”；排除时填写具体理由。

如果仍无法判断，可暂时保持“信息不足”，不要勉强作出结论。

上传后系统会尝试提取研究对象、干预方案、量表、结果、效应量、置信区间、P值、缺失数据和不良事件。自动提取可能不完整或不准确；“未自动定位”不能解释为“没有报告”。

### 第4步：核对证据分类

数字表示每类包含的研究篇数：

- **核心焦虑**：直接测量焦虑或使用焦虑量表；
- **相关情绪/行为**：测量情绪调节、问题行为、幸福感或生活质量；
- **探索性证据**：与主题有关但不能直接回答主要问题，例如只报告体适能、心理健康只是次要结局、没有适当对照或样本很小；
- **待分类**：信息不足，需要研究者查看全文后决定。

探索性证据不等于质量差，也不等于必须排除，但写作时需要降低结论强度并说明局限。逐篇检查AI建议并手工确认分类。

“自动判断”是关于证据能否合并、应如何组织的方法学建议，不是干预有效或无效的疗效结论。

### 第5步：生成论文草稿

确认已核对纳入研究和关键数值后生成草稿。投稿前仍须：

- 回看原文，核对样本量、效应值、置信区间和P值；
- 核对 PMID、DOI和参考文献；
- 由第二位评审者复核筛选和偏倚评价；
- 按目标期刊要求调整格式；
- 根据研究类型核对 CONSORT、STROBE 或 PRISMA 清单。

## 4. 保存和恢复项目

### 下载完整项目记录

导出的 JSON 包含研究问题、PubMed检索、筛选决定、排除理由、证据分类、PDF关联和解析结果以及论文草稿。JSON不包含PDF文件本体，请定期下载备份。

### 导入项目记录

选择以前下载的JSON后，系统恢复项目并检查PDF：

- PDF仍在同一个Cloudflare R2 Bucket：无需重新上传；
- PDF已删除、更换Bucket或R2不可用：系统提示重新上传。

```text
项目记录JSON：保存研究过程和PDF对应关系
Cloudflare R2：保存PDF文件本体
```

## 5. 常见名词

- **PubMed**：医学与生命科学文献数据库；
- **PMID**：PubMed论文编号；
- **DOI**：论文的长期数字标识，常用于引用和寻找出版社页面；
- **PMC**：PubMed Central，提供部分论文的合法免费全文；
- **PICO**：研究对象、干预、比较和结局；
- **效应量**：干预效果大小，不只是“是否显著”；
- **置信区间**：效应估计的不确定范围；
- **P值**：统计检验结果之一，不能单独代表临床重要性；
- **PRISMA**：系统综述报告规范及筛选流程；
- **Meta分析**：研究足够相似且数据可用时，对多个研究进行统计合并。

## 6. 工具不能替你做什么？

本工具不会也不应：

- 编造样本量、效应值、P值、DOI或参考文献；
- 把摘要当成已经核验的全文；
- 把“未报告”写成“没有发生”；
- 保证所有相关研究都已检出；
- 替代双人筛选、偏倚评价或统计专家复核；
- 把神经多样性默认描述为需要治愈的缺陷；
- 根据研究结果替个别儿童决定诊断或治疗。

## 7. 最简操作路线

```text
填写研究问题
→ 检索PubMed
→ 自动初筛摘要
→ 查找免费全文
→ 为缺少全文的候选文章上传PDF
→ 人工决定纳入或排除
→ 核对证据分类
→ 生成并修改论文草稿
→ 下载完整项目记录备份
```

遇到不确定内容时，保留“不确定”比强行作出结论更符合研究规范。
