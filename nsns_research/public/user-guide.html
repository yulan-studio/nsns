用途与定位

可追溯、可复核的人机协作证据综合工作台。

工具帮助检索PubMed、筛摘要、取得或上传全文、记录纳入与排除、分类证据并生成草稿。它帮助研究者把判断做得更清楚、更容易复核，但不独立决定研究结论，不诊断儿童，也不决定个体治疗。

在神经多样性研究中，“改善”应聚焦减轻焦虑、增加参与和提升生活质量，不能默认把神经多样性当成需要治愈的缺陷。

五步操作

1. 说明研究问题

填写研究对象、干预方式、比较对象和关注结果，然后生成检索式。

2. 检索PubMed

检查完整检索式，建议使用Best Match（相关性）排序。系统保存日期、命中数和PMID。

3. 筛摘要和核验全文

  1. 运行“自动初筛全部摘要”。
  2. 运行“查找并读取候选免费全文”。
  3. 为未排除且缺少全文的文章点击右侧“上传PDF”。
  4. 打开全文，核对对象、干预、结局、结果、缺失数据和不良事件。
  5. 选择“全文核验后纳入”或“全文核验后排除”。

无法判断时可保留“信息不足”，不要勉强作出结论。

4. 核对证据分类

逐篇检查AI建议，必要时修改分类。

5. 生成论文草稿

生成后逐句核对原文、数值和引用，并由第二位评审者复核正式筛选。

填写问题 → 检索 → 初筛摘要 → 取得全文 → 人工纳入/排除 → 分类证据 → 生成并核对草稿 → 下载项目记录

证据分类

  • 核心焦虑：直接测量焦虑或使用焦虑量表。
  • 相关情绪/行为：测量情绪调节、问题行为、幸福感或生活质量。
  • 探索性证据：与主题有关但不能直接回答主要问题，例如只报告体适能、心理健康只是次要结局、缺少适当对照或样本很小。它不等于质量差，也不等于必须排除。
  • 待分类：信息不足，需要查看全文后决定。

“自动判断”是方法学建议，不是干预有效或无效的结论。

保存与恢复

下载完整项目记录保存检索、筛选、排除理由、证据分类、PDF关联与解析结果和草稿。JSON不包含PDF本体。

导入项目记录恢复项目并检查PDF。PDF仍在相同Cloudflare R2 Bucket时通常无需重传；文件删除、换Bucket或R2不可用时会提示重新上传。

自动解析有多准确？

当前没有正式验证过的准确率百分比。在人工标注验证完成前，自动结果只能作为定位原文的线索，不能作为已核验事实。
任务用途主要风险
PMID/题名匹配关联候选文章相似题名、缺少PMID或元数据错误
对象与干预定位相关句子可能混入背景、纳入标准或其他组别
量表与结局提示测量内容可能混淆主要、次要和探索性结局
数值、P值、置信区间寻找结果位置容易错配组别、时间点和单位，必须核对
缺失与不良事件提醒检查“未自动定位”不表示“没有发生”

主要局限性

  • PubMed不能覆盖所有数据库、灰色文献和未发表研究。
  • 规则初筛可能漏掉用词不典型的研究，也可能保留无关研究。
  • PDF解析不能替代完整表格识别和统计数据提取。
  • 系统不能独立完成可靠的偏倚风险评价。
  • 不同量表、设计、对照和时间点未必适合Meta分析。
  • 论文草稿必须逐句核对，单人操作不能替代双人独立筛选。
  • 不要上传可识别儿童身份的数据。

常见名词

PMID
PubMed论文编号。
DOI
论文的长期数字标识。
PMC
提供部分论文合法免费全文的PubMed Central。
PICO
研究对象、干预、比较和结局。
PRISMA
系统综述报告规范及筛选流程。
Meta分析
研究足够相似且数据可用时，对多个研究进行统计合并。
