# 自闭症及神经多样性儿童干预研究论文助手（MVP 0.2）

第一次使用请先阅读 [快速上手说明书](USER_GUIDE.md)。

本地研究工作台，用于临床研究论文的证据整理、统计核查与可追溯写作。它不提供诊断，不替研究者或临床人员决定治疗，也不接受可识别儿童身份的数据。

## 启动

需要 Node.js 18 或更高版本。在项目目录运行：

```powershell
node server.js
```

然后打开 `http://127.0.0.1:8787`。PubMed 检索需要能够访问 NCBI；检索记录保存在 `work/search-records/`。

PDF 默认保存在本机 `work/uploads/`。部署到 Railway 后可通过 `R2_ACCOUNT_ID`、`R2_ACCESS_KEY_ID`、`R2_SECRET_ACCESS_KEY` 和 `R2_BUCKET_NAME` 四个环境变量启用私有 Cloudflare R2 存储，详见 `DEPLOY_RAILWAY.md`。

## 五步自动化流程

1. 用日常语言填写研究问题，系统整理研究对象、干预、比较和结局。
2. 自动生成并执行 PubMed 检索，保存日期、命中数、PMID 和完整检索式。
3. 上传公开全文或匿名化材料，并由研究者确认纳入、排除或等待全文。
4. 系统按核心焦虑、相关情绪/行为和探索性证据分层，提示是否适合 Meta 分析。
5. 在研究者确认关键证据后，自动生成可编辑的结构化叙述综述草稿和完整项目记录。

浏览器会在本机自动保存当前项目进度。页面中的“载入本项目已核验的6篇研究”可以直接演示从筛选到生成论文的完整流程。

## 用户下一步需要提供

- 匿名化或汇总的研究统计结果（优先使用模板）；
- 研究方案、统计分析计划及所用量表说明；
- 拟纳入的 PDF/Word 文献，或检索主题和限定条件；
- 研究设计与目标期刊，以选择 CONSORT-NPT、STROBE 或 PRISMA 2020；
- 偏好的身份表述（identity-first/person-first）及研究团队术语约定。

## 安全规则

- 未知值为空或写“未报告”，禁止猜测。
- “未报告不良事件”不等于“没有不良事件”。
- 只有摘要时必须标为 `abstract_only`，不得声称已核验全文。
- 所有稿件事实需绑定 PMID/DOI、原文位置或研究数据来源。
- AI 推论必须与原始研究发现分开陈述。
